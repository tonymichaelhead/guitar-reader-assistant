# Fonts

All three families are licensed under the SIL Open Font License 1.1. The licence texts are in `licenses/`. The files are shipped exactly as downloaded, and this project changes nothing in them: Bravura and Playfair Display carry Reserved Font Names, so a copy modified here (subset, converted or renamed) could not keep the name. `Bravura.woff2` is the whole font as its copyright holder publishes it. The EB Garamond and Playfair Display files are the Latin subsets that Fontsource serves, taken as served.

`licenses/Bravura-OFL.txt` is `redist/OFL.txt` from the Bravura repository, byte for byte. Its copyright line gives the year 2015; the notice inside the font file itself (version 1.482) gives a later year. The file is kept as upstream publishes it.

| File | Family | Use | Source |
|---|---|---|---|
| `Bravura.woff2` | Bravura (Steinberg) | All music notation | `redist/woff/Bravura.woff2` in https://github.com/steinbergmedia/bravura |
| `EBGaramond-latin-wght-*.woff2` | EB Garamond | Interface and body text | Fontsource `eb-garamond`, Latin subset, variable weight |
| `PlayfairDisplay-latin-wght-*.woff2` | Playfair Display | Titles and control labels | Fontsource `playfair-display`, Latin subset, variable weight |

## Outlines taken from Bravura

`src/export/glyph-outlines.js` holds the outlines of six Bravura glyphs (G clef, black notehead, time-signature 4, sharp, flat, natural) as path data, for the PDF export. It is a derived work under the same licence: it names Steinberg as the copyright holder and points to `licenses/Bravura-OFL.txt`. It is not a font, and nothing in a generated PDF is named Bravura. It is generated by `scripts/extract-glyph-outlines.mjs` from `redist/otf/Bravura.otf` and `redist/Bravura.json` (version 1.482) in the Bravura repository; neither of those two files is kept here.

## Where the files came from

The Fontsource files were fetched from `https://cdn.jsdelivr.net/fontsource/fonts/<id>:vf@latest/latin-wght-<normal|italic>.woff2`.
